# Seven Trumpets Narrative

A cinematic, story-driven mobile web app walking through the Seven Trumpets of Revelation 8–11 — narration, character dialogue, mini-games, and Scripture, built as a TanStack Start (React) SPA.

## Development

You'll need Node.js and npm.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Tech stack

- React 19 + TanStack Start / TanStack Router
- Tailwind CSS 4
- Zustand for app state
- Framer Motion for animation
- Radix UI primitives (via shadcn/ui components)
