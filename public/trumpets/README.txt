Drop per-trumpet placeholder/poster images here, named to match
each trumpet file's `imageSrc` field:

  trumpet1.jpg
  trumpet2.jpg
  trumpet3.jpg
  trumpet4.jpg
  trumpet5.jpg
  trumpet6.jpg
  trumpet7.jpg

Any image format works (.jpg/.png/.webp) — just update the `imageSrc`
path in the matching src/data/trumpets/trumpetN.ts file if you use a
different extension. Until a file exists, that trumpet's Cinematic
scene just falls back to the animated particle/gradient background —
nothing breaks.
